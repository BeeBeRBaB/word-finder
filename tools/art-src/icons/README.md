# Subject icons

The icons the subject backgrounds draw are Microsoft's [Fluent Emoji](https://github.com/microsoft/fluentui-emoji),
MIT (`LICENSE-fluent-emoji.txt`), in its flat style, each icon in its own colours. Until 2026-11-11
the Background page also offered the high-contrast style as One colour; the owner chose the flat
one alone, and git history has the other. Only the drawings the maps in `../iconmap/` name are kept
here. Run from the repo root.

- `fluent-emoji-flat.json`: each drawing's SVG body on a 32x32 grid, by its Fluent Emoji name.
  Generated by `vendor.mjs`; don't edit it by hand.
- `facing.json`: the icons drawn side-on, facing `left` or `right`, so the motions can turn them to
  face the way they move (people running and walking were left out when two styles had to agree).
- `vendor.mjs`: copies the drawings out of the Iconify package. It drops what the canvas
  doesn't need (whole-square clips, drop shadows), writes out reused paths, turns a gradient into
  its first colour and a masked inside stroke into a stroke half as wide, and refuses any drawing
  still pointing at something elsewhere.

## Adding or changing an icon

1. Find the name at https://icon-sets.iconify.design/fluent-emoji-flat/ and put it in the subject's
   list in `../iconmap/<category>.json` (4–6 names, hero first).
2. Unpack the package somewhere outside the repo (nothing is installed):

   ```bash
   mkdir -p /tmp/sets/flat
   (cd /tmp/sets/flat && npm pack @iconify-json/fluent-emoji-flat && tar -xzf *.tgz)
   node tools/art-src/icons/vendor.mjs /tmp/sets/flat
   ```

3. If the icon is side-on, add it to `facing.json` after checking which way it faces.
4. `node tools/art-src/iconmap/emit.mjs` rewrites `src/backgrounds/subject-icons.js` and the
   drawing files under `src/backgrounds/icons/`. The unit suite fails until it has run.

Changing which files hold which icons, or the exports, needs a `CACHE` bump in `sw.js`, as for any
change to an export under `src/backgrounds/`.
